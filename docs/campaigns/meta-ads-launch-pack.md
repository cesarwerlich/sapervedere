## 4. Mapa de Rastreamento, Atribuição & Engenharia de Analytics

O ecossistema Saper Vedere foi construído nativamente com uma arquitetura de conversão em 2 etapas, garantindo atribuição de ponta a ponta sem perda de dados por bloqueios de cookies ou iframes de terceiros.

```
[ANÚNCIO META ADS]
    │  (com parâmetros UTM + fbclid)
    ▼
[LANDING PAGE] (/lp/operacoes | /lp/gtm | /lp/diagnostico)
    │  • utm.ts captura UTMs na URL e salva no sessionStorage ('sv_utms')
    │  • Meta Pixel dispara PageView
    │  • PostHog captura $pageview com UTMs completas
    ▼
[PREENCHIMENTO DO LEADFORM]
    │  • Validação anti-spam (Cloudflare Turnstile + Honeypot)
    │  • POST /api/leads envia dados + UTMs para webhook/CRM
    ▼
[REDIRECIONAMENTO: /obrigado] (1st-party domain)
    │  • ObrigadoTracker dispara:
    │      1. fbq('track', 'Lead', { content_name: 'Lead Saper Vedere' })
    │      2. posthog.capture('generate_lead', { step: 'obrigado_page' })
    │      3. window.dataLayer.push({ event: 'lead_confirmed' })
    ▼
[GOOGLE CALENDAR EMBED NA /obrigado]
    │  • O lead seleciona a data e horário da conversa sem risco
    │    de quebrar a atribuição anterior do Pixel
```

---

### 4.1. Configuração do Meta Pixel & Conversões Customizadas

1. **Meta Pixel Base**:
   - Já integrado no `app/layout.tsx` via script assíncrono condicionado à variável `NEXT_PUBLIC_META_PIXEL_ID`.
   - Dispara automaticamente `fbq('track', 'PageView')` em todas as rotas da aplicação.

2. **Evento Padrão de Conversão (`Lead`)**:
   - O evento de conversão primário é disparado exclusivamente na página `/obrigado` através do componente `ObrigadoTracker` em `app/components/LeadForm.tsx`:

   ```javascript
   fbq('track', 'Lead', { content_name: 'Lead Saper Vedere' });
   ```
   - Isso assegura que cliques acidentais ou formulários incompletos **nunca** poluam a otimização de conversão da campanha no Gerenciador de Anúncios.

3. **Configuração de Conversão Customizada no Meta Events Manager**:
   - Nome: `Lead Confirmado — Saper Vedere`
   - Evento Base: `Lead` (ou tráfego com URL contendo `/obrigado`)
   - Regra de URL: `URL contém /obrigado`
   - Otimização: Marcar como Conversão Prioritária no painel do Meta.

4. **Recomendação de Evolução (Meta Conversions API - CAPI Server-Side)**:
   - Para alcançar nota máxima de Event Match Quality (EMQ 8.5+), recomenda-se que a rota `POST /api/leads` envie uma requisição server-side diretamente para a Graph API do Facebook (`https://graph.facebook.com/v19.0/{PIXEL_ID}/events`) com email e telefone criptografados em SHA256, `client_user_agent`, `client_ip_address` e `fbc`/`fbp`.

### 4.3. Guia de Configuração de Funil no PostHog

No painel do PostHog, crie um **Funil de Conversão (Funnels)** com as seguintes 4 etapas para monitorar a jornada do visitante pago em tempo real:

#### Etapas do Funil no PostHog:

1. **Passo 1 (Visita na Landing Page)**:
   - Evento: `$pageview`
   - Filtro de Propriedade: `utm_medium` = `paid_social` **E** `current_url` contém `/lp/`
2. **Passo 2 (Início do Formulário)**:
   - Evento: `lead_form_started`
   - Filtro de Propriedade: `form_name` = `LeadForm`
3. **Passo 3 (Envio do Formulário & Validação)**:
   - Evento: `lead_submitted`
   - Propriedades capturadas: `service` (ex: `coo`, `gtm`, `diagnostico`), `stage` (ex: `Tração e crescimento (6 a 15 pessoas)`), `utm_campaign`, `utm_content`.
4. **Passo 4 (Confirmação na Página Obrigado)**:
   - Evento: `generate_lead`
   - Filtro de Propriedade: `step` = `obrigado_page`

#### Métricas de Acompanhamento (Dashboards PostHog):

- **Drop-off de Formulário**: Percentual de visitantes que visualizam a LP vs. iniciam o formulário (esperado: > 15%).
- **Taxa de Conclusão do Formulário**: `lead_form_started` → `lead_submitted` (esperado: > 60%).
- **Segmentação por Estágio**: Breakdown de leads por receita e tamanho de equipe para refinar o targeting do Meta Ads.
- **Session Replay Filter**: Criar playlist de gravações filtrando por:
  - `utm_campaign` is set
  - `lead_submitted` did not happen
  - Permite inspecionar pontos de fricção, dúvidas sobre a copy ou abandono no campo de telefone/desafio.
